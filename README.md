# Spring Boot JDBC Example

A Spring Boot application demonstrating database operations using **Spring JDBC** and `JdbcTemplate`.

## 🚀 Technologies

- Java
- Spring Boot
- Spring JDBC
- JdbcTemplate
- Maven
- SQL

## 📌 Features

- Database connectivity using Spring Boot
- Performing SQL operations using `JdbcTemplate`
- Repository-based database operations
- Working with SQL queries and result sets
